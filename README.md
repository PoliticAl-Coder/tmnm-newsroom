Search, author, category, series and sort controls are included. Series filtering grows as additional genuinely published series editions are identified.

## Adding articles
Edit the `ARTICLES` array in `index.html` using the canonical title, original author, appropriate category, optional series and edition number, accurate publication date, and actual recorded Substack or Facebook permalink. Add only previously published material; do not infer publication from draft documents. If a destination URL is missing, omit that link.

Owner-confirmed publications and provider-receipt-backed publications are valid source classifications, but should not be conflated. Original source provenance and incomplete-URL tracking are kept in TMNM's private editorial records.

## Activate the public webpage
To enable hosting, an authorised repository administrator may open https://github.com/PoliticAl-Coder/tmnm-newsroom/settings/pages, select **Deploy from a branch**, choose **gh-pages** and **/(root)**, Save, then verify the page loads.
