# Truth Matters News Media (TMNM)

## Project Purpose
TMNM is a semi-automated digital newsroom system to generate, organise, brand, and prepare news content for publication across social media, YouTube, OBS, and future platforms.

### Core Objectives
- Generate articles and images
- Organise outputs by date and desk
- Manage branding consistently
- Support OBS/YouTube production
- Scale into a fully automated content pipeline

### Repository Structure
- `characters/`: Persona configs, rules, references
- `prompts/`: Reusable prompt templates
- `branding/`: Logos, graphics, branding rules
- `automation/`: Scripts for folder creation, pipelines, batch files
- `obs/`: OBS scene plans, overlays, assets
- `workflows/`: Operating procedures, checklists, publishing flows

### Google Drive Structure (Local Mirror)
- `TMNM/Avatars/`: Character avatars
- `TMNM/Studios/`: Studio backgrounds
- `TMNM/Graphics/`: Article images, memes, charts
- `TMNM/Daily Output/YYYY-MM-DD/DeskName`: Daily generated content
- `TMNM/Ready To Post/`: Final approved content

### Automation Goals
- Create repo and Google Drive folder structures
- Generate desk folders by date
- Standardise filenames
- Save generated content in correct folders
- Prepare screen packs and article/image output pairs
- Support OBS asset packaging
- Enable one-command newsroom runs

### Branding Rules
- Network: Truth Matters News Media (#TruthMattersNewsMedia, #TMNM)
- Default graphic: 1920x1080, branding bottom-right
- Signature: AW cursive, bottom-left
- Visual style: Semi-realistic cartoon/editorial

### Personas
- Politic_Al: Editor-in-Chief, political analysis
- RetiredTrader: Senior Market Analyst, must include disclaimer
- BallisticBen: Military analysis, must include #RememberTheCivilians
- AshaObserves: Society & Economics
- ConspiracyCousin: Satirical, marked with tildes

---

This system is the canonical TMNM newsroom automation and content pipeline. All scripts, folders, and outputs must follow the above rules and structure.
